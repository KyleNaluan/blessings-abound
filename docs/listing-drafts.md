# Listing drafts

This page is generated by `uv run python -m app.draft_eval` in `api/`, so edit the script or the prompt in `api/app/listing_drafts.py` instead of this page.
It measures how often the model's own listing draft passes the claim checker, before any staff edit.
The prompt, the model and the checker's rules are described in [architecture.md](architecture.md#listing-drafts).

## Result

**46 of 48 drafts pass the checker, 95.8%.**
2 were flagged and would have gone to the fixed template, and 0 got no usable reply from either model.
The template itself passes on 48 of 48 items.

Flags by rule: banned word 0, brand 0, size 0, number 0, condition 2.

## Limits

- **Not measured: apparel and Channel B.** Every item here is games or hardware, which only Channel A takes, so these results say nothing about clothing drafts.
- Every item has the same staff entries, pre-owned and not complete in box, with nothing recorded about testing, so the rules about flaws, sizes and working claims are barely exercised here, and the unit tests in `api/tests/test_claims.py` cover them instead.
- A pass means the checker found no unsupported claim, not that a person read the draft and found it good, and the checker can miss a claim it has no rule for.
- With this few items, one draft moves the pass rate by about 2 points.
